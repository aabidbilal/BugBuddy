# BugBuddy

BugBuddy is a VS Code extension that helps you understand syntax and runtime errors with clear explanations, an interactive error rank panel, and a friendly terminal to run your code.

## Features

### ⭐ Error Rank Sidebar
Shows an image based on how many errors your current file has:
- Low errors → Friendly icon  
- Medium errors → Warning icon  
- High errors → Danger icon  

### ⭐ Hover Explanations
Hover over any error to see a simple BugBuddy explanation.

### ⭐ BugBuddy Terminal
A custom terminal that shows friendly error messages and warnings.

### ⭐ Run File Button
Run JS, Python, and C files directly with BugBuddy’s friendly terminal.

## Requirements
None. Works on any VS Code installation.

## Known Issues
Still in early development — some features may not work perfectly on all systems.
